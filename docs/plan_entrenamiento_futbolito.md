# Plan de Entrenamiento de Futbolito

## Propósito

Este plan organiza 8 semanas de entrenamiento de futbolito con una lógica progresiva. La idea central es aprovechar la disponibilidad de cancha sin transformar todos los días en partidos intensos.

## Disponibilidad semanal

| Día | Disponibilidad | Enfoque | Intensidad |
| --- | --- | --- | --- |
| Lunes | Cancha | Base aeróbica + conducción + fuerza preventiva | Media |
| Martes | Oficina | Descanso real + micro-pausas | Muy baja |
| Miércoles | Oficina | Descanso total o movilidad mínima | Muy baja |
| Jueves | Cancha | Agilidad + pase + core estable | Media |
| Viernes | Cancha | Técnica suave + recuperación activa | Baja |
| Sábado | Cancha | Técnica + remate + pichanga controlada | Media-alta |
| Domingo | Cancha | Simulación de partido o descarga con balón | Variable |

## Fases de progresión

| Semanas | Fase | Intensidad | Foco |
| --- | --- | --- | --- |
| 1–2 | Adaptación inicial | 5–6/10 | Aprender estructura y cuidar técnica |
| 3–4 | Construcción | 6–7/10 | Aumentar repeticiones técnicas |
| 5–6 | Intensidad controlada | 7–8/10 | Acercarse al ritmo real con pausas |
| 7–8 | Transferencia al juego | Ritmo de partido controlado | Decisiones, juego reducido y finalización |

## Componentes del plan

### Trabajo físico

- Resistencia intermitente.
- Agilidad y cambios de dirección.
- Frenadas controladas.
- Core y fuerza preventiva.

### Trabajo técnico

- Conducción.
- Pase rasante.
- Control orientado.
- Remate colocado.
- Uso de pierna no dominante.

### Trabajo táctico

- Pase y apoyo.
- Ocupación de espacios.
- Presión tras pérdida.
- Finalización con ventaja.
- Decidir antes de recibir.

## Evaluación sugerida

| Indicador | Registro | Meta |
| --- | --- | --- |
| Asistencia | Día completado / no completado | 4–5 días útiles |
| Carga percibida | RPE 1–10 | Promedio 5–7 |
| Dolor | Escala 0–10 | Mantener 0–3 |
| Técnica | Pases acertados / intentos | 70% o más |
| Confianza | Autoevaluación 1–5 | Subir al menos 1 punto |

## Escala de dolor

| Dolor | Decisión |
| --- | --- |
| 0–3/10 | Entrenar normal, cuidando técnica |
| 4–5/10 | Bajar intensidad y eliminar sprints/remates fuertes |
| 6/10 o más | Suspender sesión intensa |
| Dolor irradiado, hormigueo o debilidad | Consultar profesional |
