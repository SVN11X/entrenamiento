# Plan de Entrenamiento para Futbolito / Futsal

## Ajuste de disponibilidad

A partir de esta versión, el plan considera la siguiente disponibilidad semanal:

| Día | Disponibilidad | Enfoque |
| --- | --- | --- |
| Lunes | Cancha | Base aeróbica + conducción + fuerza preventiva |
| Martes | Oficina | Descanso real + micro-pausas |
| Miércoles | Oficina | Descanso total o movilidad mínima |
| Jueves | Cancha | Agilidad + pase + core estable |
| Viernes | Cancha | Técnica suave + recuperación activa |
| Sábado | Cancha | Técnica + remate + pichanga controlada |
| Domingo | Cancha | Simulación de partido o descarga con balón |

## Criterio principal

Tener cancha cinco días no significa entrenar fuerte cinco días. La cancha se usa con distintos propósitos:

1. Técnica.
2. Agilidad.
3. Recuperación activa.
4. Remate.
5. Simulación de partido.

Martes y miércoles se respetan como días de oficina y recuperación.

## Fases

| Semanas | Fase | Intensidad | Foco |
| --- | --- | --- | --- |
| 1–2 | Adaptación real | 5–6/10 | Usar cancha sin sobrecargar |
| 3–4 | Construcción | 6–7/10 | Aumentar volumen técnico |
| 5–6 | Intensidad controlada | 7–8/10 | Bloques similares a juego |
| 7–8 | Transferencia | Ritmo de partido controlado | Pichanga con mejores decisiones |

## Seguridad

| Dolor | Decisión |
| --- | --- |
| 0–3/10 | Entrenar normal, cuidando técnica |
| 4–5/10 | Bajar intensidad, eliminar sprints, saltos y remates fuertes |
| 6/10 o más | Suspender sesión intensa |
| Dolor que baja por la pierna | Consultar profesional |
| Hormigueo o debilidad | Consultar profesional |
